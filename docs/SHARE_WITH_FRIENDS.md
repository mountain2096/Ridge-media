# Chia sẻ Ridge với bạn bè

1. Cài Cloudflare Tunnel: `winget install Cloudflare.cloudflared`.
2. Đặt biến môi trường `FRIENDS_MONGO_URI` trỏ tới một database thử nghiệm riêng.
3. Từ thư mục gốc dự án, chạy `npm run share`.
4. Gửi URL được in trong banner cho bạn bè.
5. Nhấn Ctrl+C để dừng ứng dụng và các tunnel.
6. Không dùng mật khẩu quản trị thật khi chia sẻ.
